# Starboard

**Open-source Harness, drawn as a night sky.**

Starboard reads public GitHub data for the [`harness`](https://github.com/harness) organization. Each star is a repo. Brighter / bigger stars have more GitHub stargazers. Recent activity twinkles.

No Harness PAT. No account ID. No org. No project.

```
        .  *    .   ★     .
     *      .    harness
        .     *      .
```

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000), click a star, wander into the source.
