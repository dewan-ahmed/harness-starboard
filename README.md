# Starboard

**Open-source Harness, drawn as a night sky.**

Starboard reads public GitHub data for the [`harness`](https://github.com/harness) organization. Each star is a repo. Brighter / bigger stars have more GitHub stargazers. Recent activity twinkles.

No Harness PAT. No account ID. No org. No project.

```
        .  *    .   ★     .
     *      .    harness
        .     *      .
```

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000) in your local browser, click a star, wander into the source.

Use that loopback URL, not a Cursor preview or LAN IP. Those can hit a corporate proxy and return “Accessible only on corporate network.”
